# Six Balls Puzzle

A web-based two-player puzzle battle game with hexagonal grid mechanics.

## Quick Start

```bash
npm install
cd shared && npm run build
cd server && npm run dev &
cd client && npm run dev
```

Open http://localhost:3000

## Controls

| Key | Action |
|-----|--------|
| <- -> | Move |
| Up Arrow | Rotate |
| Down Arrow | Soft drop |
| Space | Hard drop |
